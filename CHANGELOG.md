# Changelog

All notable changes to this package are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the
project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-11-02

### Added
- Project Inventory editor window (Tools → Project Inventory).
- Incremental asset index kept in sync through an AssetPostprocessor.
- Type / folder / label / size / unreferenced filters and search syntax.
- Virtualized thumbnail grid and sortable list views.
- Details panel with interactive preview, metadata, labels, dependencies and Used By.
- "Show in Project Inventory" Project-window context menu entry.
